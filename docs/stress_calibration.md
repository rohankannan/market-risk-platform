# Stress calibration

Generated by `python -m risk.jobs.calibrate_stress` at `9b21020-dirty` from the committed snapshot. Do not edit by hand.

Basis: overlapping **20-business-day** moves, 4,966 windows spanning 2007-02-01 to 2026-08-06, each factor in its own return convention (log returns, basis points, vol points).

A one-month horizon is long enough to contain an episode and short enough that the book's positions would plausibly still be on. Overlapping windows keep every observed episode in the sample at the cost of correlated draws - the same trade the RNIV note makes for k-day shocks, and the reason severities below are quoted as quantiles rather than return periods.
